## About

데이터를 분석해 의미 있는 인사이트를 발견하고, 언어를 이해하는 모델을 공부합니다.<br />
데이터 분석과 머신러닝을 기반으로 **NLP 프로젝트**를 진행해 왔으며, 현재는 **LLM·RAG·AI Agent**를 학습하고 있습니다.

장기적으로는 분석과 모델링 경험을 바탕으로, 실제 문제를 해결하는 **LLM 애플리케이션 엔지니어링** 영역으로 확장하는 것이 목표입니다.
